01. Algoritmos

Um algoritmo é como uma receita de bolo. São passos exatos que o computador deve seguir.

  • Entrada: Os ingredientes.
  • Processamento: O ato de bater e assar.
  • Saída: O bolo pronto!

No ciberespaço, tudo funciona com algoritmos: do seu jogo favorito ao GPS.

02. O Cérebro: Arduino

O Arduino é uma placa que permite controlar coisas físicas (luzes, motores) usando código.

Pinos: São os braços do Arduino.

Microcontrolador: É o processador central.

03. Sintaxe Básica

Veja como falamos com o Arduino:

void loop() {
  digitalWrite(13, HIGH); // Liga o LED
  delay(1000);          // Espera 1s
  digitalWrite(13, LOW);  // Desliga o LED
}
